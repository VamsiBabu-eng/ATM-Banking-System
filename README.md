# ATM Banking System
==================
ATM Banking System
==================

1. INTRODUCTION

---

The ATM Banking System is a command-line
application developed using Python and MySQL.

This system simulates basic ATM operations
and allows users to securely access their accounts.

The system enables users to perform:

* Account Login (Authentication using PIN)
* Deposit Money
* Withdraw Money
* Check Account Balance
* Transaction Recording

---

2. SYSTEM REQUIREMENTS

---

Hardware Requirements:

* PC or Laptop

Software Requirements:

* Python 3.x
* MySQL Server
* MySQL Connector

Installation:
pip install mysql-connector-python

---

3. SETUP AND EXECUTION

---

1. Start MySQL Server

2. Create Database:

CREATE DATABASE atm_db;

3. Run Program:

python atm.py

---

4. MAIN MENU

---

1. Login
2. Exit

---

5. DASHBOARD

---

1. Deposit
2. Withdraw
3. Balance
4. Exit

---

6. WORKFLOW

---

Login → Perform Operations → Exit

---

7. FEATURES

---

* Secure Login
